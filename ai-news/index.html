Anthropic Research @AnthropicAI Anthropic research blog

The components of agent memory: how dreaming helps Claude organize experience and correct mistakes

Anthropic 研究博客详解 agent 记忆的组件设计：Claude 要从经验中学习，必须在不值知道下一个任务是什么之前，就决定什么值得记住。文章给出四层记忆结构：可搜索的对话记录、精炼的记忆笔记、可复用的知识表达（如 wiki），以及注入未来会话的少量上下文。最有意思的是 dreaming 机制——利用离线算力回顾日志、纠正错误、把未经验证的猜测与确认过的教训区分开再整理归档。文章同时警告：记忆不是越多越好，存下所有东西的 agent 会把时间耗在检索陈旧笔记上。对正在生产环境跑 agent 团队的工程团队，这是一份记忆治理的参考架构。

Anthropic's research blog breaks down the components of agent memory: for Claude to learn from experience, it must decide what is worth remembering before it knows what comes next. The post describes a four-layer hierarchy spanning searchable transcripts, distilled memory notes, reusable representations such as wikis, and a small slice of context injected into future sessions. The most striking piece is the dreaming mechanism: offline compute revisits logs, corrects mistakes, separates confirmed lessons from untested guesses, and organizes everything before the next task. Anthropic also warns that more memory is not automatically better, since an agent that stores everything wastes time searching stale notes. A useful reference architecture for any team running agents in production.
