OpenAI's Brian Fioca and Bill Chen break down how Codex-Max was trained: not as a smarter GPT-5, but as a model post-trained specifically for long-running coding agents, with personality, communication, planning and self-checking as first-class objectives. Anthropic Engineering @AnthropicAI Anthropic 工程博客，Lance Martin 等撰写

Scaling Managed Agents: Decoupling the Brain from the Hands

这篇工程博客回答的是一个比模型能力更基础的问题：怎么设计一套系统，去承载「今天还不存在的程序」。Anthropic 最初把 Claude 的推理循环、代码沙箱、会话日志全塞进一个容器，好处是简单，代价是容器变成了一只「宠物」——坏了就全完了，而且出了故障根本分不清是推理出问题、网络丢包还是容器挂了。他们的解法是把大脑（Claude 与 harness）、双手（沙箱与工具）、会话（append-only 事件日志）三层拆开，双手退化成极简接口 execute(name, input) → string，沙箱可以是容器、手机甚至宝可梦模拟器。效果是 p50 首 token 延迟降约 60%、p95 降超过 90%，凭证存在沙箱外的保险库，生成的代码永远碰不到真密钥。更深的一层洞察是：harness 里编码的都是对模型能力边界的假设，而这些假设会过期——他们为 Sonnet 4.5 的「上下文焦虑」加的上下文重置，换到 Opus 4.5 就成了累赘。

This engineering post tackles a problem more foundational than model capability: how to design a system for programs as yet unthought of. Anthropic first packed Claude's reasoning loop, code sandbox and session log into a single container. Simple, but the container became a pet: lose it and everything is gone, and when it stalls you cannot tell whether the harness, the event stream or the container itself failed. The fix is to decouple three layers: the brain (Claude and its harness), the hands (sandboxes and tools), and the session (an append-only event log). Each hand collapses into a minimal interface, execute(name, input) to string, so a sandbox can be a container, a phone or a Pok&eacute;mon emulator. Time-to-first-token dropped about 60% at p50 and over 90% at p95, credentials live in a vault outside the sandbox, and generated code never touches real keys. The deeper lesson: harnesses encode assumptions about model limits that expire. Context resets added for Sonnet 4.5's context anxiety became dead weight on Opus 4.5.
