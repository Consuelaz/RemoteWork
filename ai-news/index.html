Anthropic Research @AnthropicAI 可证明推理：给 AI 回答开一张防伪身份证

Provable Inference: FlashProve Brings Cryptographic Proof That a Specific Model Wrote an Output

Anthropic 发布研究博客并开源 FlashProve 系统，基于零知识密码学证明（zkSNARK）实现「可证明推理」：服务商先对模型权重生成加密承诺，之后每次回答都附带证明文件，用户无需模型权重、无需重跑模型，即可独立验证回答确实来自指定模型 —— 直接命中第三方 API 中转偷偷换小模型、推理服务器被篡改等行业信任痛点。已在 400B 参数的 Llama 4 Maverick 上测试：单张 H100 证明吞吐约 110 token/s，每 1024 token 请求证明文件约 19MB，CPU 验证约 17 秒。证明生成仍需普通推理 70-95 倍 GPU 时间，且证明的是来源而非正确性，但模型「身份证」已从学术设想走进工程实操。

Anthropic open-sourced FlashProve, a provable inference system based on zkSNARKs: providers commit to model weights cryptographically, then attach a proof to each response so users can independently verify the output came from the promised model without accessing weights or re-running inference. It targets real trust gaps like third-party API resellers silently swapping in cheaper models. Tested on the 400B-parameter Llama 4 Maverick: ~110 tokens/s proof throughput on a single H100, ~19MB proof per 1024-token request, ~17s CPU verification. Proof generation still costs 70-95x normal inference GPU time, and it proves provenance, not correctness — but verifiable model identity is now an engineering reality.
